# Minor Project 04: To-Do App & Notes App

## Project Overview
A single React application housing both a To-Do task manager and a persistent Notes app built using React hooks and local storage.

## Features Implemented
- **To-Do App**: Add, toggle complete/pending, edit, delete tasks, and localStorage persistence.
- **Notes App**: Create, view, edit, delete notes, and localStorage persistence.
- **Responsive Design**: Mobile-friendly layout.

## Technologies Used
- React.js (Functional components, useState, useEffect)
- JavaScript ES6+
- CSS3

## Setup Instructions
1. Clone the repo: `git clone <YOUR_REPO_URL>`
2. Install dependencies: `npm install`
3. Run local server: `npm run dev`
